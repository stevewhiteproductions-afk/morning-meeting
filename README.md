# Morning Meeting

Touchscreen smart-board app for the classroom morning meeting: calendar, ten frames, place-value counters, letter and sight word of the day, weather, feelings and more.

Open `index.html` in a browser, or serve this folder with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

- Bottom bar: slide grid, previous/next, drawing tools, move/reset, kiosk mode.
- Right-click advances one slide. Arrow keys also work.
- Kiosk mode: exit by holding the door button (top-left) for 1.5 seconds.
- Settings (on the Links slide): edit links, change the Good Morning background.
- Photo Gallery (last slide): add or delete photos in Settings → Photos. On Chrome, Edge or a Chromebook you can pick a local (or Google Drive) folder to keep them as files; otherwise they're saved in the browser.

Everything runs in the browser; no server code. Settings and board positions are saved in that browser only.
